Run a node

One static binary is the whole node. The genesis is baked in — an empty datadir joins chain 3961 and follows the blocks the signers confirm.

# Install in one line (Linux / macOS — verifies SHA-256)
curl -fsSL https://ferminux.net/install.sh | bash

# Zero config — an empty datadir syncs the Ferminux Network (chain 3961)
ferminux

# With local JSON-RPC for wallets and tooling
ferminux --http --http.api eth,net,web3

Chain data lives in ~/.ferminux (macOS: ~/Library/Ferminux; Windows: %LOCALAPPDATA%\Ferminux). The node discovers peers through the built-in bootnodes at boot1–3.ferminux.net. The previous command name, ferminux-geth, still works. Running a node does not make you a signer: signer authorisation is granted on-chain.
